# Política de privacidad

Esta skill de Alexa es de uso personal y privado, no está publicada en la
tienda pública de Alexa. Conecta el dispositivo Alexa del usuario con su
propia instancia autoalojada de Home Assistant mediante OAuth (account
linking).

## Qué datos se manejan

- La skill no recolecta, almacena ni comparte información personal por sí
  misma.
- El account linking usa un flujo OAuth estándar: Alexa obtiene un token de
  acceso de la instancia de Home Assistant del propio usuario para poder
  enviarle comandos (encender/apagar el robot aspiradora). Ese token vive
  únicamente entre Alexa y el servidor de Home Assistant del usuario.
- No se recopila información de menores de edad.
- La skill no muestra publicidad ni procesa pagos.
